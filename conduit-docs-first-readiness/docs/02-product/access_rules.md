# Access Rules

## Current Scope

The current project documentation does not define:

- Authentication.
- User accounts.
- User roles.
- Permissions.
- Remote storage.
- Backend access rules.
- Server-side APIs.
- Admin dashboards.

## Product Rule

Backend authentication, account systems, and remote access-control systems are out of scope unless future project files explicitly add them.

## Architecture Implication

The calculator must run client-side for core app logic. Implementation agents must not add backend clients, databases, external API dependencies, telemetry, analytics, or account infrastructure without a documented requirement.

## TBD / Open Decisions

- None for current docs-first scope. Access systems are simply not part of the documented product at this time.
