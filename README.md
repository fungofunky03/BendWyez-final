# Conduit Bending Calculator

Docs-first planning repository for a job-site-first PWA that helps electricians calculate conduit bends (offsets, saddles, kicks, and 90s).

## Current Status

- Phase 0 (documentation readiness): complete
- Phase 1 (project initialization and architecture): authorized next phase
- Production app scaffold/code: not started yet

## Repository Structure

- `conduit-docs-first-readiness/` — project source-of-truth docs and execution memory files
  - `task_plan.md` — authorized phase and implementation checklist
  - `progress.md` — verified completion status
  - `findings.md` — architecture/math discoveries and open decisions
